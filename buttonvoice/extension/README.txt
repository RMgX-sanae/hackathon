ButtonVoice 按钮失语症 / 0.1.0

这份安装包不需要 Node.js、命令行或本地服务器。
双击 welcome.html 查看完整安装说明。

安装
1. 解压 ZIP，保留 ButtonVoice 文件夹。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择直接包含 manifest.json 的 ButtonVoice 文件夹。
5. 将扩展固定到工具栏，打开普通网页，点击扩展图标 → 检查当前网页。
安装后请保留原文件夹。开发者模式只是本地安装开关，无需开发软件。

先体验
点击扩展弹窗中的“先试试演示网页”。内置四个模拟网站及普通网页示例，离线可用。
选择按钮问题 → 定位并确认用途 → 填写名称 → 应用并复查 → 朗读前后变化。
没有可靠命名依据时，需要人工填写。通用网页不自动批修。

键盘与语音引导
点击“进入网页，按 Tab 浏览”，自动开启朗读并聚焦当前对象。
之后 Tab 前进、Shift+Tab 后退，停留在网页按钮时自动读出当前名称、顺序和位置。
连续切换取消旧语音；未确认的建议不会被当作真实名称。面板按钮不会触发这套播报。
可关闭“Tab 聚焦与切换时自动朗读”。这不会改变原来的 Tab 操作或替用户点击。
Alt + Shift + 左右方向键：切换并聚焦问题对象。
Alt + Shift + Enter：聚焦当前对象，不替用户点击。
Alt + Shift + U：返回确认面板。Alt + Shift + I：朗读位置与上下文。
也可用普通 Tab 操作面板按钮；已有读屏软件时可关闭自动朗读。
名称线索冲突时不预选；编辑或状态变化后取消旧确认。无法确定时可以暂时跳过。
疑似可点击而没有按钮语义的元素单独保留，不计入名称修复成功。

图标含义预设
支持常见 SVG 爱心：选择收藏或点赞，确认这批含义一致后批量应用。
选择本身只生成草稿，不改 DOM；已有名称、手动编辑或跳过的项目不参与批量。
状态可读取时同步取消收藏或取消点赞；不推断未提供的状态。
更换含义不会覆盖已应用名称，需要撤销后重新确认。
不识别任意图片、Canvas 或 CSS 绘制的爱心。

撤销与保存
名称修改只对当前页面生效，不会保存到网站服务器。
可以撤销单项、撤销本轮修改，或者撤销并退出。
网站已经再次改动的名称会被保留，不强行覆盖。
页面刷新通常恢复网站原来的内容。永久修复需要网站维护者采用并发布代码。

本地运行
仅使用 activeTab 和 scripting 权限，在主动点击时访问当前页面。
不调用 AI 或第三方语音 API，不上传页面内容，不保存浏览历史。
中文朗读使用浏览器报告为本地的语音；没有音色时保留文字对比。
语音模拟按钮名称变化，不替代真实 VoiceOver / NVDA 测试。

范围
只检查主页面普通 DOM 中按钮的可访问名称，不遍历 iframe 或 Shadow DOM。
浏览器设置页、扩展商店及其他受保护页面无法注入。
本地 file:// 页面需在扩展详情里允许“访问文件网址”。
名称非空不代表准确，也不代表通过了整个网站的无障碍审计。
本版面向桌面 Chrome / Edge；尚未上架商店，不支持手机或 Safari / Firefox。

构建与验证
安装包由当前工作区源码构建；详细验证结果位于项目 README.md 与 test-results。
Chrome / Edge 同为目标浏览器，实际浏览器验证范围以项目 README 为准。
