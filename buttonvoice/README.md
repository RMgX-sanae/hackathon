# ButtonVoice · 按钮失语症

让每一个没有名字的按钮，重新拥有自己的声音。

可反复演示的本地 Web Demo：扫描校园二手商城中的真实按钮，发现可访问名称缺失，给出有依据的规则建议，修改实际 DOM，并重新计算名称验证结果。只检查按钮名称缺失，不是完整的 WCAG 审计工具。

这是当前工作区中的独立 Vite 项目，原有 Flow 原型保持原样。

## 用完整测试网页做现场演示

打开 `release/ButtonVoice-Demo/index.html`，或解压 [离线演示包](release/ButtonVoice-Demo.zip) 后双击其中的 `index.html`。四个模拟场景沿用原测试页的界面，增加“测试声音”和“开启 ButtonVoice”入口。无需开发环境、本地服务器或扩展安装，请保留整个文件夹。

1. 点击“测试声音”，确认输出正常。
2. 选择场景，开启面板，选择一项问题并“朗读修复前”。
3. 确认名称、应用并复查，再“朗读修复后”。爱心也可使用收藏 / 点赞含义预设。
4. 点击“进入网页，按 Tab 浏览”，之后用 Tab / Shift+Tab 移动。聚焦网页按钮会自动朗读实际名称、顺序和位置。切换场景、点击“重置”即可开始新一轮。

离线演示默认开启“Tab 聚焦与切换时自动朗读”，切换场景会保留本轮开关选择。工具面板不触发按钮自动播报。连续切换会取消旧语音，只读最终停留的对象；未确认的建议不会被当作真实名称朗读。

面板只扫描当前 `#demo-root`，不计入外层切页按钮。此版本在演示文件中内置面板，不是 Safari 扩展。原 `ButtonVoice_MockPages` 素材未改动。开发者可用 `npm run build:demo` 重建。

2026-10-11 已在真实 Safari 中从 `file://` 打开，观察到本地中文语音开始与结束、实际按钮名称变化：校园场景为 9 个按钮、5 个缺失，修复常用服务按钮后为 9 / 4 / 1。浏览器中播放了“按钮”和“将课表与考试加入常用服务，按钮”。用户已确认之前在内置浏览器的模拟网页朗读可以听见；Safari 的这一轮记录是实际播放事件验证。另有 9 项离线加载、限定扫描范围、场景切换、重置和状态同步的增量检查通过，见 `test-results/offline-demo-report.json`。

## 普通用户：安装浏览器扩展

已提供可直接分发的 [Chrome / Edge 安装包](release/ButtonVoice-Chrome-Edge.zip)，不需要 Node.js、命令行或服务器。尚未上架扩展商店。

1. 解压 ZIP，保留 `ButtonVoice` 文件夹。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，开启“开发者模式”。这只是本地扩展安装开关。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的 `ButtonVoice` 文件夹。
4. 打开一个普通网站，点击工具栏里的 ButtonVoice → “检查当前网页”。首次使用也可以从弹窗进入离线体验页。

完整说明：[welcome.html](release/ButtonVoice/welcome.html)，可以直接双击打开。当前机器已有解压目录 `release/ButtonVoice/`，可直接选它安装。请保留安装目录。

扩展扫描当前主页面的普通 DOM，工具面板通过 Shadow DOM 隔离，不会把自身按钮计入结果。未知用途需人工命名，网站提示文本只作为待确认候选。确认后写入真实 `aria-label` 并重新计算名称；可定位、试听、复制片段、撤销单项或全部修改。

通用按钮的按下或展开状态变化时，原修复会标为待核对；内置登记示例和已确认的爱心预设可根据可读取的状态同步名称。撤销只恢复仍属于本工具的修改，保留网站随后写入的新值。刷新通常恢复原页面；永久发布修复需要网站维护者参与。

只请求 `activeTab` 与 `scripting` 权限，在点击扩展时访问当前页；没有后台服务、所有网站常驻权限、网络请求或浏览历史存储。浏览器内部页面及扩展商店不能检查；本地 HTML 需在扩展详情允许“访问文件网址”。当前不遍历 iframe 或 Shadow DOM，不支持手机、Safari、Firefox。

扩展源码在 `extension/`，复用 `src/audit.js`、`scanner.js`、`speech.js`；开发者重新打包运行 `npm run build:extension`，生成解压文件夹与 ZIP。普通用户不需要运行构建命令。

## 键盘引导与含义确认

无需找鼠标指针：工具可直接把键盘焦点移到目标，提供所在区域、关联标题、页面顺序、附近已命名按钮和状态。定位不会激活按钮。面板中的普通按钮也可通过 Tab 操作；已有读屏软件时可关闭自动朗读，避免重复播报。

| 快捷键 | 操作 |
| --- | --- |
| Tab / Shift+Tab | 按网页原有顺序前进 / 后退；自动朗读开启时播报聚焦按钮的名称和位置 |
| Alt + Shift + ← / → | 切换并聚焦上一个 / 下一个问题对象 |
| Alt + Shift + Enter | 聚焦当前对象，不点击 |
| Alt + Shift + U | 返回确认面板的输入框或上下文说明 |
| Alt + Shift + I | 朗读位置与上下文 |

自动朗读不会接管 Tab 键或自动激活按钮，链接和输入框仍遵循网页原来的焦点顺序。若 Safari 的 Tab 跳过按钮，可在 Safari 设置的“高级”中启用“按下 Tab 键以高亮显示网页上的每一项”，参见 [Apple 键盘操作说明](https://support.apple.com/en-gb/guide/safari/cpsh003/mac)。

网页提示只形成候选名称，冲突线索不会自动预选。编辑名称或改变按钮状态后，旧确认会失效；可暂时跳过不确定项目，缺失计数仍保留。缺少按钮语义的疑似可点击控件单独列出，需要网站维护者补全角色和键盘行为，不能仅写入名称就算修复。

“爱心含义预设”允许把当前页中识别到的未命名爱心解释为“收藏”或“点赞”。选择只生成草稿；确认整批含义一致后才应用，并逐个复查实际名称。已有名称、手动编辑和暂时跳过的项目不参与批量。页面提供可读取的选中状态时，同一预设内同步为“取消收藏”或“取消点赞”；更换含义不会覆盖已应用名称，需要先撤销再确认。同页混用两种含义时，请逐项处理。

当前爱心识别覆盖已登记的常见 SVG 路径、同页 SVG `use` 引用和图标标记；不识别任意图片、Canvas 或 CSS 图形，也不推断网站未提供的状态。预设只对本轮当前页生效，不会跨站持久保存。

## 本地实现边界

- `src/scanner.js`：仅在 `#preview` 内发现按钮，通过 `dom-accessibility-api` 的 `getRole`、`computeAccessibleName` 计算角色和名称。操作元数据不参与缺失判定。
- `src/suggestions.js`：独立的规则建议函数。根据登记的 `data-action` 和 `aria-pressed` / `aria-expanded`，给出搜索、收藏、菜单、购物车等建议。不认识的用途返回“需要人工确认”。
- `src/audit.js`：保存首次扫描的原始名称、HTML、属性；应用前复查；写入 `aria-label` 后重新计算实际名称。仅匹配预期时记为有效修复，冲突保留并提示。批量操作跳过已有名称、未知用途和用户正在编辑的建议。
- `src/demo.js`：真实商城 DOM 和最小业务交互。收藏、菜单和购物车的已管理名称跟随状态变化；重置重建初始示例。
- `src/scenes.js`：挂载用户提供的四个模拟网页，接入其真实收藏状态。建议引擎读取登记的 `data-demo-action` 和具体条目标题，不使用素材包的预设问题清单作为扫描结果。
- `src/speech.js`：浏览器原生 `SpeechSynthesis`，只选择浏览器报告为本地的中文音色。处理音色加载、播放失败、重复播放与旧回调取消。
- `src/main.js`：控制台、代码复制、高亮、状态通知和重置协调。高亮只添加 CSS 样式类，不插入命名文本。
- `src/orientation.js`：上下文描述、问题导航、焦点转移和返回确认位置，必要的临时 `tabindex` 在离开时恢复。
- `src/presets.js`：爱心识别、含义选择、整组确认和状态命名；与扩展共用同一套逻辑。

运行时不调用 AI、OCR、视觉、推理或第三方语音 API，不加载本地模型，没有后端、账号、数据库或云存储。字体使用本机字体，图标、商品图片和 JavaScript 随项目提供；名称检测、建议与修复可离线运行。需要通过本地 HTTP 服务打开，不能直接双击 `index.html`。

修改建议输入框只改变草稿；点击应用才写入 DOM。修复前快照在本轮演示中保持不变。计数来自实际复查，重复点击不会累计。

## 支持范围与限制

- 支持原生 `button`、具有按钮角色的常见元素，以及 `input` 的 `button`、`submit`、`reset`、`image` 类型。
- 额外列出部分带点击标记或可聚焦且呈点击样式的非语义控件，独立于按钮统计。不保证发现仅通过 JavaScript 监听器绑定、没有语义和其他线索的控件。
- 名称计算支持可见文本、ARIA 引用和标签、图片 `alt`、原生关联标签及默认名称。`aria-describedby` 不被冒充为名称。
- 排除常见 `hidden`、`aria-hidden`、`display:none`、`visibility:hidden`、`inert`、`content-visibility:hidden` 和关闭的 `details` 内容，考虑祖先影响。视觉隐藏或隐藏但被合法引用的文本仍能参与名称计算。
- 非空名称只表示“未发现名称缺失”，不保证名称准确、键盘行为正确或满足全部无障碍要求。
- `aria-labelledby` 等命名来源可能优先于新写入的标签；不删除原属性强行制造修复成功。
- Web 演示只扫描本页示例；检查其他网页请使用随项目提供的浏览器扩展。两个入口均不遍历 iframe 或 Shadow DOM。
- 页面刷新与“重置演示”会清除本轮修改，不保存到磁盘或服务器。外部变化可重新扫描；示例中的状态变化会自动复查。
- 模拟素材的响应式布局会隐藏部分商品或功能，实际扫描数可能小于素材包 README 的完整页面数。调整窗口宽度后点击“重新扫描”。
- 语音是名称变化的模拟，真实屏幕阅读器的措辞、状态播报和阅读顺序可能不同。
